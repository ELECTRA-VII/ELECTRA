ESP32 Weather Station

A Wi-Fi connected weather station that measures temperature, humidity and pressure — shown on a local OLED and streamed to a live web dashboard.

ESP32 BME280 Arduino 3D-printed case
How I built it Source code

Overview

I wanted a weather station that didn't depend on a cloud service. The ESP32 reads a BME280 sensor every 30 seconds, shows the values on a 0.96" OLED, and serves a small web page over Wi-Fi so I can check it from my phone.

The whole thing runs on 5 V over USB and fits inside a 3D-printed enclosure. Total cost was around $18.

Features

📶 Wi-Fi dashboard

Live readings served from the ESP32 itself — no external server needed.

🌡️ Accurate sensing

BME280 gives temperature, humidity and barometric pressure in one chip.

🖥️ Local OLED

Works standalone — the display shows everything even without Wi-Fi.

🔋 Low power

Deep sleep between samples keeps it running for days on a battery.

Build Steps

  1. Wire it up on a breadboard

    Connect both I²C devices to GPIO 21/22 and run an I²C scanner sketch to confirm the addresses.

  2. Flash the firmware

    Install the ESP32 board package in the Arduino IDE, then open firmware/weather_station.ino and set your Wi-Fi credentials.

  3. Solder to perfboard

    Move the circuit to perfboard once it works. Keep the I²C traces short to avoid noise.

  4. Print and fit the case

    Print the enclosure, cut a window for the OLED, and hot-glue the board in place.

  5. Calibrate

    Compare against a known thermometer and apply an offset in the config if needed.

Code

The core loop reads the sensor and pushes values to the web server:

void loop() {
  float t = bme.readTemperature();
  float h = bme.readHumidity();
  float p = bme.readPressure() / 100.0F;

  display.clearDisplay();
  display.setCursor(0, 0);
  display.printf("%.1f C\n", t);
  display.printf("%.0f %%\n", h);
  display.printf("%.0f hPa\n", p);
  display.display();

  server.handleClient();
  delay(30000);
}

Full source, libraries and the PlatformIO config are in the GitHub repository.

Results

The station has been running continuously for three weeks. Temperature tracks within 0.4 °C of a commercial indoor sensor, and the web dashboard responds in under 200 ms on the local network.
